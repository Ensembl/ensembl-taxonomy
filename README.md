ensembl-taxonomy
================

This repository contains code for dealing with the NCBI Taxonomy database.

## Acknowledgements

Much of the code, methods and schema used in this package draw heavily from earlier work in Ensembl projects,
in particular [ensembl-compara](https://github.com/Ensembl/ensembl-compara),
[ensembl-taxonomy](https://github.com/Ensembl/ensembl-taxonomy/)
and the Taxonomy API of [ensembl-py](https://github.com/Ensembl/ensembl-py/).
We acknowledge and are grateful for the contributions of those who have gone before us.

And of course, a big thank you to the NCBI for the Taxonomy resource.

The rank hierarchy used in this package is as described by
[Schoch et al. (2020)](https://doi.org/10.1093/database/baaa062),
with updates based on the NCBI Insights blog posts,
[Upcoming changes to NCBI Taxonomy classifications](
https://ncbiinsights.ncbi.nlm.nih.gov/2024/06/04/changes-ncbi-taxonomy-classifications/)
and [NCBI Taxonomy updates to virus classification](
https://ncbiinsights.ncbi.nlm.nih.gov/2025/04/25/ncbi-taxonomy-updates-virus-classification-april-2025/).
